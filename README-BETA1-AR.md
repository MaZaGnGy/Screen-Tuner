# Screen Tuner — Beta 1

الإصدار1.0.0-beta.1، كود20006، مبني على exp5 مع تصحيح متابعة التطبيق النشط وتحميل الإعدادات أثناء الإقلاع.

- اختيار ثابت أو متغير165/144/120/90/60 لكل تطبيق من Supported apps داخل إعدادات النظام، بما فيها البحث.
- اتباع التردد الحالي ديناميكيًا، أو افتراضي النظام.
- تحديد الكل، إلغاء الكل، اتباع التردد الحالي للجميع، مع الحفاظ على استعادة الافتراضيات الأصلية.
- الكيبورد60 بعد300ms، والفيديو60/30 أثناء المشاهدة دون لمس، وحدود الحرارة تظل نافذة.
- كل خصائص AOD واللغة وإعادة تشغيل النطاقات من النسخة السابقة محفوظة.

ثبتت التجربة على الجهاز أن متغير120 يعمل بالمعرض مع الاختيار العام165. وأكد المستخدم عمل السياسة على جميع الاختيارات الثابتة والمتغيرة. مشكلة144→1Hz منفصلة ولم تُحل.

تثبيت أو تحديث APK يحتاج إعادة تشغيل الهاتف كاملة لتحميل جزء النظام. زرRestart scopes يعيد SystemUI وAOD فقط.

التوافق المراجع: OnePlus15 / CPH2745، ColorOS17، إطار يدعمmodern libxposed API102. المصادر المنشورة لا تشمل مفتاح التوقيع أو بيانات فحص الهاتف الخاصة.
